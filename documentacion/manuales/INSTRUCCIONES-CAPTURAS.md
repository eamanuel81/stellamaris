# Instrucciones para Capturas de Pantalla

Este documento lista todas las capturas de pantalla necesarias para completar los manuales.

## Formato de las Imágenes

- **Formato:** PNG o JPG
- **Resolución recomendada:** Mínimo 1280x720 píxeles
- **Nomenclatura:** Usar nombres descriptivos en minúsculas con guiones

## Proceso para Agregar Capturas

1. Toma las capturas siguiendo la lista anterior
2. Guárdalas en la carpeta `documentacion/manuales/imagenes/`
3. Usa los nombres exactos especificados
4. Actualiza los manuales (ya tienen marcadores de posición)

---

## Notas Técnicas

- Usa herramientas como:
  - Snipping Tool (Windows)
  - Recorte de pantalla (macOS)
  - Herramientas del navegador (F12 > Screenshot)
- Recorta solo el área relevante (sin barras del navegador innecesarias)
- Asegúrate de que el texto sea legible
- Usa datos de ejemplo apropiados (sin información real sensible)
