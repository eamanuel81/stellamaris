# **App Name**: Stella Maris Manager

## Core Features:

- User Authentication: Authentication: Secure login for administrators and employees, with password reset functionality and temporary password generation.
- Task Management: Task Management: Administrators can create, edit, and delete tasks with details like title, description, required skills (e.g., driving), optional task type, and estimated duration.
- Task Assignment: Employee Task Assignment: A separate menu for administrators to assign tasks to employees, with a configurable calendar interface that reflects the working hours from 6 AM to 1 AM.
- Employee Task View: Employee Task View: Employees can log in to view their assigned tasks and update the task status (assigned, accepted, completed).
- User directory: User Directory: A directory searchable by name, DNI, nickname etc.
- Real-time Notifications: Notifications: Automated notifications to employees upon task assignment and to administrators when employees update task statuses.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) to evoke a sense of calm and professionalism, reminiscent of the sea.
- Background color: Light gray (#F5F5F5) to provide a clean and neutral backdrop for the interface.
- Accent color: Subtle orange (#FFAB40) for interactive elements, drawing from maritime signal colors without overpowering the design.
- Body and headline font: 'PT Sans' (sans-serif) to ensure readability and a modern feel. 
- Use clear and recognizable icons related to tasks, user roles, and filters to aid navigation and improve user understanding.
- Design a clean and intuitive layout with clear information hierarchy, using a grid system to ensure consistency and a professional appearance.
- Implement subtle animations for task status changes and notifications to provide engaging feedback without distracting the user.
